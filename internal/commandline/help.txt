Usage: ark [OPTIONS] <dirname>

Description:
   Yet another alternate [directory|repository] represent text generator tool.

Sub commands:
  setup <client>                                   Configure Ark for a supported coding agent (claude, cursor, codex, cline, copilot-vscode, copilot-cli).
  mcp-server                                       Start MCP server.
  mcp-init                                         Add ark MCP server config to .mcp.json.
  syntax <file>                                    Parse file and output AST using Tree-sitter.
  symbol <file>                                    Extract symbols (functions, types, etc.) from file.
  skill                                            Generate Ark MCP skill for Claude Code / OpenAI.
  instruction <target>                             Print agent instructions for using Ark MCP (target: claude, codex, cursor, cline, copilot-vscode, copilot-cli).


general (text generator mode) options:
  -h, --help                                       Show this help message and exit.
  -v, --version                                    Show version.
  -o, --output-filename <filename>                 Specify ark output txt filename. (optional. default: 'ark_output.txt')
  -b, --scan-buffer <number|byte-string>           Specify the line scan buffer size. (optional. default: '10M')
  -f, --output-format <'txt'|'md'|'xml'|'arklite'> Specify the format of the output file. (optional. default: 'txt').
  -m, --mask-secrets <'on'|'off'>                  Specify Detect the secrets and convert it to masked output. (optional. default: 'on').
  -a, --allow-gitignore <'on'|'off'>               Specify enable .gitignore filter rule. (optional. default: 'on')
  -A, --additionally-ignorerule <filepath>         Specify a file containing additional ignore rules. (optional.)
  -n, --with-line-number <'on'|'off'>              Specify Whether to include file line numbers when outputting. (optional. default: 'on')
  -d, --ignore-dotfile <'on'|'off'>                Specify ignore dot files. (optional. default 'off')
  -x, --pattern-regex <regxp>                      Specify watch file pattern regexp. (optional.)
  -i, --include-ext <extention>                    Specify include file extention. Allows comma separated list.(optional.)
  -g, --exclude-dir-regex <regexp>                 Specify include directory ignore pattern regexp. (optional.)
  -G, --exclude-file-regex <regexp>                Specify watch file ignore pattern regexp. (optional.)
  -e, --exclude-ext <extention>                    Specify watch exclude file extention. Allows comma separated list. (optional.)
  -E, --exclude-dir <dirname>                      Specify watch exclude dirname. Allows comma separated list. (optional.)
  -c, --compless                                   Specify flag compress the output result with arklite. (optional.)
  -s, --skip-non-utf8                              Specify flag to ignore files that do not have utf8 charset. (optional.)
  -S, --silent                                     Specify flag process without displaying messages during processing. (optional.)
  -D, --delete-comment                             Specify flag strip comments based on language detection. (optional.)

setup <client> options:
  <client>                                         Target coding agent: claude, cursor, codex, cline, copilot-vscode, copilot-cli.
                                                   copilot-vscode = GitHub Copilot in VS Code (Chat / Agent mode; project .vscode/mcp.json only)
                                                   copilot-cli    = GitHub Copilot CLI (project .github/mcp.json only; refused if <root>/.mcp.json
                                                                    already defines "ark", which Copilot CLI prefers)
                                                   --global is not supported for copilot-vscode / copilot-cli; neither configures the GitHub-hosted agent.
                                                   (ark setup without a client is a deprecated Claude alias.)
  -h, --help                                       Show help message.
  -n, --name <name>                                Claude skill/slash-command name (Claude only. default: current directory name).
  -p, --ark-path <path>                            Path to ark binary. (optional. default: auto-detect)
  -r, --root <dirname>                             Root directory to serve. (optional. default: $pwd)
  -g, --global                                     Configure Ark in the client's user-level MCP configuration.
  -f, --force                                      Replace an existing Ark-owned MCP entry (never touches other config).

mcp-init options:
  -h, --help                                       Show help message.
  -p, --ark-path <path>                            Path to ark binary. (optional. default: auto-detect)
  -r, --root <dirname>                             Root directory to serve. (optional. default: $pwd)
  -n, --name <name>                                MCP server name in settings.json. (optional. default: 'ark')
  -g, --global                                     Write to ~/.claude/settings.json. (optional. default: .mcp.json)
  -f, --force                                      Overwrite existing MCP server entry. (optional.)

mcp-server options:
  -r, --root <dirname>                             Specify the mcp-server serve root dirname(optional. default: $pwd)
  -t, --type <http|stdio>                          Specify the mcp-server serve type. (optional. default: 'stdio')
  -p, --http-port <number>                         Specify the mcp-server port. (optional. default: 8522)
  -b, --scan-buffer <number|byte-string>           Specify the line scan buffer size. (optional. default: '10M')
  -m, --mask-secrets <'on'|'off'>                  Specify Detect the secrets and convert it to masked output. (optional. default: 'on').
  -a, --allow-gitignore <'on'|'off'>               Specify enable .gitignore filter rule. (optional. default: 'on')
  -A, --additionally-ignorerule <filepath>         Specify a file containing additional ignore rules. (optional.)
  -d, --ignore-dotfile <'on'|'off'>                Specify ignore dot files. (optional. default 'off')
  -x, --pattern-regex <regxp>                      Specify watch file pattern regexp. (optional.)
  -i, --include-ext <extention>                    Specify include file extention. Allows comma separated list.(optional.)
  -g, --exclude-dir-regex <regexp>                 Specify include directory ignore pattern regexp. (optional.)
  -G, --exclude-file-regex <regexp>                Specify watch file ignore pattern regexp. (optional.)
  -e, --exclude-ext <extention>                    Specify watch exclude file extention. Allows comma separated list. (optional.)
  -E, --exclude-dir <dirname>                      Specify watch exclude dirname. Allows comma separated list. (optional.)
  -s, --skip-non-utf8                              Specify flag to ignore files that do not have utf8 charset. (optional.)
  -D, --delete-comment                             Specify flag strip comments based on language detection. (optional.)

instruction options:
  <target>                                         Instruction target: claude, codex, cursor, cline, copilot-vscode, copilot-cli.
                                                   Prints Markdown to stdout; writes no files. Suggested destination per target:
                                                     claude          -> CLAUDE.md
                                                     codex           -> AGENTS.md
                                                     cursor          -> AGENTS.md
                                                     cline           -> .clinerules/ark.md
                                                     copilot-vscode  -> .github/copilot-instructions.md
                                                     copilot-cli     -> .github/copilot-instructions.md
  -h, --help                                       Show help message.

syntax options:
  -h, --help                                       Show help message.
  --lang <language>                                Specify language (go, typescript, tsx, javascript, python, php).
  --format <'text'|'json'>                         Specify output format. (optional. default: 'text')

symbol options:
  -h, --help                                       Show help message.
  --lang <language>                                Specify language (go, typescript, tsx, javascript, python, php).
  --format <'text'|'json'>                         Specify output format. (optional. default: 'text')

skill subcommands:
  skill                                            Auto mode - detect and generate appropriate skill.
  skill init                                       Generate Repository Skill (full repo-specific skill).
  skill add-explorer                               Add Explorer Skill (companion to existing skills).
  skill update                                     Update Ark-managed skills (preserves user files).
  skill inspect                                    Show detected skills and repository analysis.

skill options:
  -h, --help                                       Show help message.
  --name <name>                                    Specify skill name. (optional. auto-determined if not set)
  --output <dirname>                               Specify output directory. (optional. default: skills/<name>)
  --archive                                        Create ZIP archive. (optional.)
  --force                                          Overwrite existing skill. (optional.)

skill update options:
  --force                                          Force update even if user modifications detected.
  --dry-run                                        Show what would be updated without making changes.


Arguments:
  <byte-string>                                    byte size string. (ex) 10M, 100k
  <dirname>                                        The directory name.
  <extention>                                      file extention name.(example: go,ts,html)
  <regexp>                                         regular expresion string. Interpreted with golang `regexp` package.
